# Smart AI — умные боты для Arma 3

Мод меняет **поведение** ботов, а не их меткость. Боты не стреляют как аимбот,
зато воюют как отделение: прижимают огнём, обходят с фланга, выкуривают гранатами,
вытаскивают раненых, отходят под дымом и зовут подмогу. Против них интересно играть,
потому что их можно перехитрить, а сами они тоже хитрят.

Работает в одиночной игре, в мультиплеере и с headless-клиентами.
**Требуется [CBA_A3](https://steamcommunity.com/workshop/filedetails/?id=450814997).** ACE3 поддерживается, но не обязателен.

## Что умеют боты

| Поведение | Как это выглядит |
|---|---|
| **Реальные укрытия** | Под обстрелом боец ищет рядом дерево, камень, стену, машину или комнату в доме и проверяет, что оттуда его действительно не видно со стороны стрелка. Ложится или садится и смотрит на угрозу. |
| **Подавление** | Если по кому-то стреляют, сосед (в первую очередь пулемётчик) открывает ответный огонь по **примерному** направлению на стрелка. Бот не знает вашу точную позицию. |
| **Фланговые манёвры** | При контакте на 50–450 м отделение делится: группа огневой поддержки с пулемётами прижимает вас огнём, манёвренная группа обходит с того фланга, где больше укрытий и меньше простреливается, и атакует сбоку. |
| **Гранаты** | Если вы в 12–38 м, сидите за укрытием или в здании, в вас полетит осколочная граната по навесной. Рядом со своими гранаты не бросают. Работают и модовые гранаты (тип определяется по конфигу боеприпаса). |
| **Отступление** | Отделение, потерявшее половину бойцов против превосходящего противника, ставит дымовую завесу, оставляет прикрывающего и отходит на 120–200 м, а там перегруппировывается. |
| **Помощь раненым** | Ближайший боец с аптечкой (медик в приоритете, к тяжёлым бегут в первую очередь) бросает дым, подбегает и лечит. Если помочь некому, раненый лечит себя сам. |
| **Медицина ACE** | С ACE medical бойцы лечат по-настоящему: останавливают кровотечение бинтами, делают СЛР при остановке сердца, ставят капельницы (кровь → плазма → физраствор), колют адреналин без сознания и морфин от боли. Расходники берутся у медика, затем у раненого. |
| **Обмен разведданными** | Группа, вступившая в бой, сообщает по «радио» соседям в радиусе 800 м примерные позиции противника (с задержкой 2–6 с). Соседи настораживаются и ищут вас, но не получают «волхак». |
| **Подкрепления** | Группа в меньшинстве вызывает ближайшую свободную группу. Та заходит под углом, а не по той же дороге. |
| **Поиск** | Потеряв контакт, боты не забывают о вас, как ванильный ИИ, а идут прочёсывать последнюю известную позицию. |
| **Техника** | Экипаж подбитой машины спешивается (стрелок остаётся, если пушка работает) и дальше воюет как пехота. |
| **Навыки** | Высокая внимательность и командование, человеческая меткость (регулируется), без панического бегства. |

## Установка

1. Скачайте сборку из вкладки **Actions** (артефакт `SmartAI`) или соберите сами (см. ниже).
2. Распакуйте папку `@sai` (или переименуйте её в `@SmartAI`) в папку Arma 3.
3. Подключите в лаунчере **CBA_A3** и Smart AI. В мультиплеере мод **обязателен на сервере** и на headless-клиентах.
   На клиентах игроков он нужен только для меню настроек CBA и маркеров отладки.

### Сборка

Нужен [HEMTT](https://github.com/BrettMayson/HEMTT):

```
hemtt build      # dev-сборка в .hemttout/
hemtt release    # архив в releases/
```

## Настройки (CBA)

Все настройки в **Настройки → Параметры аддонов → Smart AI**, у каждого пункта есть подсказка
на русском. Настройки глобальные: на сервере действует серверное значение.
Для конкретной миссии их можно зафиксировать в Eden (**Атрибуты → Параметры аддонов**)
или в файле `cba_settings.sqf` миссии/сервера:

```sqf
force SAI_skill = 0.4;
force SAI_reinforce = false;
force SAI_aceMedical = true;
```

| Раздел | Переменная | По умолчанию | Описание |
|---|---|---|---|
| Общие | `SAI_enabled` | `true` | Главный выключатель |
| | `SAI_debug` | `false` | Отладочные маркеры и сообщения |
| | `SAI_tick` | `3` | Интервал оценки обстановки, с |
| Навыки | `SAI_applySkills` | `true` | Применять профиль навыков |
| | `SAI_skill` | `0.6` | Сложность стрельбы 0.1..1 (тактика умная при любом значении) |
| Тактика | `SAI_cover`, `SAI_suppression`, `SAI_flanking`, `SAI_grenades`, `SAI_smoke`, `SAI_fallback`, `SAI_search` | `true` | Отдельные модули тактики |
| Медицина | `SAI_buddyAid` | `true` | Помощь раненым в бою |
| | `SAI_selfAid` | `true` | Самопомощь, если помочь некому |
| | `SAI_aidRadius` | `80` | Как далеко боец побежит к раненому, м |
| | `SAI_aceMedical` | `true` | Лечение средствами ACE (если ACE загружен) |
| Взаимодействие | `SAI_intel`, `SAI_intelRadius` | `true`, `800` | Обмен разведданными |
| | `SAI_reinforce`, `SAI_reinforceRadius` | `true`, `1500` | Подкрепления |
| | `SAI_respectWaypoints` | `true` | Не уводить группы с маршрутов миссии |

## Для мейкеров миссий

Мод не ломает сценарий: группы с активными вейпоинтами миссии воюют умно, но никуда
не перенаправляются (для поиска, подкреплений и отхода). Группы в режиме `CARELESS`,
группы с игроками и бойцы с `disableAI "PATH"` (гарнизоны) не двигаются модом.
Режимы огня `BLUE`/`GREEN`/`WHITE` (не стрелять) соблюдаются.

```sqf
_grp setVariable ["SAI_disable", true, true];     // полностью отключить мод для группы
_grp setVariable ["SAI_noMove", true, true];      // не давать группе приказов на перемещение
_grp setVariable ["SAI_noReinforce", true, true]; // группа не откликается на запросы подкрепления
_unit setVariable ["SAI_keepSkill", true];        // не менять навыки этого бойца
```

## Быстрый тест

В редакторе поставьте игрока и откройте консоль отладки (выполнение локально):

```sqf
[] call SAI_fnc_debugTest;                  // вражеское отделение в 350 м перед вами
[400, east, true] call SAI_fnc_debugTest;   // плюс дружественное ИИ-отделение рядом
```

Включится режим отладки: на карте видно состояние каждой группы
(зелёный — спокойны, хаки — настороже, красный — бой, оранжевый — обход с фланга,
розовый — отход, жёлтый — поиск, синий — идут на подмогу).

## Совместимость

- Не включайте вместе с другими модами на поведение ИИ (LAMBS Danger, VCOM AI, ASR AI и т.п.):
  они будут отдавать ботам противоречащие приказы.
- ACE3 совместим. Smart AI лечит раненых **в бою**, а встроенный ИИ-медик ACE (`ace_medical_ai`)
  продолжает работать в спокойной обстановке, они друг другу не мешают.
- Требуется Arma 3 версии 2.14 или новее.

## Структура

```
addons/main/
  config.cpp             CfgPatches, CfgFunctions, CBA XEH
  XEH_preInit.sqf        регистрация настроек CBA, запуск после их синхронизации
  stringtable.xml        English / Русский
  functions/core/        цикл, «мозг» группы, навыки, знание о противнике
  functions/tactics/     укрытия, подавление, фланги, гранаты, отход, поиск, техника
  functions/support/     разведданные, подкрепления, помощь раненым (ванилла и ACE)
  functions/debug/       маркеры, лог, тестовый бой
```
